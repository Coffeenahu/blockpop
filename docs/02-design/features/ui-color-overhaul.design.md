# PDCA Design: UI 컬러 스킴 개편 (Monochrome Khaki Theme)

> 사용자가 제공한 카키/라임 팔레트를 기반으로 한 미니멀 단색 디자인 명세서입니다.

## 1. 컬러 팔레트 정의 (Color Palette)

| 색상 코드 | 용도 | 설명 |
|:---:|:---|:---|
| **#313628** | Main Background | 진한 카키 계열의 메인 배경 |
| **#cadf9e** | Primary Block Color | 모든 블록에 적용될 밝은 라임 색상 |
| **#a4ac96** | Text & Item Secondary | 차분한 그레이시 그린 (UI 요소 및 보조 텍스트) |
| **#ffffff** | Highlight Text | 점수 및 주요 가시 텍스트 |

## 2. UI 요소별 적용 계획

### 2.1 전역 스타일 (App.css 변수)
- `--bg-color`: `#313628`
- `--grid-bg`: `rgba(0, 0, 0, 0.15)` (배경보다 약간 어두운 느낌의 투명도 활용)
- `--grid-border`: `#a4ac96` (그레이시 그린 경계선)
- `--text-color`: `#a4ac96` (기본 텍스트 색상)

### 2.2 블록 팔레트 (constants.ts)
- **단색화**: `BLOCK_COLORS`의 모든 요소를 `#cadf9e`로 통일하여 미니멀한 단색 디자인 달성.

### 2.3 버튼 및 인터페이스
- **아이템 버튼**: 배경색 `#313628`에 경계선 및 아이콘 `#a4ac96` 적용.
- **점수/콤보**: `#cadf9e` 또는 `#ffffff`를 사용하여 가독성 확보.

## 3. 구현 세부 사항
- **그라데이션 활용**: 배경에 `#073B4C`에서 `#0C637F`로 이어지는 은은한 방사형 그라데이션을 적용하여 깊이감을 부여합니다.
- **블록 대비**: 블록들이 배경색 위에서 잘 보이도록 미세한 `drop-shadow` 또는 `border` 효과를 조정합니다.

## 4. 기대 효과
- 기존의 단순한 블랙/그레이 톤에서 벗어나 독창적인 'Block Pop'만의 브랜드 컬러 정립.
- 높은 채도의 블록 색상을 사용하여 시각적인 즐거움과 집중도 향상.
