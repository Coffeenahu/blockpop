# 설계서 - BLOCK POP (v2.1.0)

## 1. 게임 개요
- **장르**: 퍼즐 (블록 배치 및 줄 제거)
- **핵심 메커니즘**: 8x8 그리드에 무작위로 생성되는 블록(피스)을 배치하여 가로 또는 세로 줄을 완성하고 제거하는 게임.

## 2. 데이터 구조
### 2.1 그리드 (Grid)
- `GridData`: `Cell[][]` (8x8 배열)
- `Cell`: `{ filled: boolean, color?: string, pop?: boolean }`
### 2.2 피스 (Piece)
- `PieceShape`: `{ id: string, shape: number[][], color: string, difficulty: string }`

## 3. 핵심 시스템
### 3.1 블록 배치 및 줄 제거
- 사용자가 피스를 그리드 빈 공간에 드래그하여 배치.
- 배치가 완료되면 가로/세로 줄이 꽉 찼는지 확인 (`checkLines`).
- 완성된 줄은 `pop` 상태로 전환되어 애니메이션 후 제거됨.
### 3.2 콤보 시스템 (Combo System)
- 연속으로 줄을 제거할 경우 점수 배율 적용.
- 유예 횟수(Grace turns)를 제공하여 콤보 유지를 돕음.
### 3.3 시각 효과 (Visual Effects)
- 블록 제거 시 파티클 효과 발생.
- 점수 획득 시 팝업 텍스트 표시.

## 4. UI/UX 및 조작 (업데이트됨)
### 4.1 포인터 기반 드래그 시스템
- **통합 포인터 이벤트**: 마우스와 터치를 모두 지원하는 `PointerEvents` 기반 조작.
- **수직 오프셋 (Lift)**: 드래그 중인 블록은 포인터보다 `DRAG_LIFT_PX (80px)` 위에 표시되어 사용자의 손가락이나 포인터가 블록을 가리지 않도록 함.
- **좌표 보정**: 실제 블록이 위치한 좌표를 기준으로 `document.elementFromPoint`를 호출하여 정확한 그리드 셀을 감지.
- **시각적 피드백**: 
  - 드래그 중인 피스는 1.1배 확대 및 그림자 효과 적용.
  - 배치 가능한 위치를 실시간으로 그리드에 반투명하게 표시(Preview).

## 5. 점수 체계
- 블록 배치: 셀 개수 당 10점.
- 줄 제거: 기본 100점 + 콤보 배율 적용.
- 콤보 배율: `1 + (콤보 수 * 0.5)`.

## 6. 게임 종료 조건
- 현재 생성된 모든 피스를 그리드 어디에도 배치할 수 없을 때 게임 종료.
