# Block Pop 계획서 (Plan Document)

> Version: 1.0.0 | Created: 2026-03-08 | Status: Draft

## 1. 요약 (Executive Summary)
"Block Pop"은 "Block Blast"에서 영감을 받은 블록 퍼즐 게임입니다. 플레이어는 8x8 그리드에 다양한 모양의 블록을 배치하여 가로 또는 세로 줄을 완성합니다. 완성된 줄은 사라지며 점수를 획득하고, 더 이상 블록을 배치할 공간이 없으면 게임이 종료됩니다.

## 2. 목표 (Goals and Objectives)
- 고품질의 인터랙티브 웹 기반 블록 퍼즐 게임 개발.
- 블록 배치 및 줄 제거 시 부드러운 애니메이션과 시각 효과 구현.
- 표준 블록 퍼즐 규칙을 따르는 견고한 게임 로직 보장.

## 3. 범위 (Scope)
### 포함 범위 (In Scope)
- 핵심 게임 엔진: 8x8 그리드 관리, 조각 생성 (테트리스 스타일 모양).
- 게임 로직: 조각 배치 유효성 검사, 줄 제거 (가로/세로), 점수 계산.
- UI/UX: 알록달록한 블록, 그리드 표시, 점수 트래커, "Game Over" 화면.
- 시각 효과: 줄 제거 시 톡 터지는 "Pop" 애니메이션.
- 기술 스택: React (TypeScript) 및 Vanilla CSS.

### 제외 범위 (Out of Scope)
- 멀티플레이어 기능.
- 리더보드/백엔드 연동 (로컬 하이스코어만 지원).
- 고급 사운드 효과 또는 배경 음악 (시각 효과에 우선 집중).

## 4. 성공 기준 (Success Criteria)
| 기준 (Criterion) | 지표 (Metric) | 목표 (Target) |
|------------------|---------------|---------------|
| 기능성 | 핵심 루프 완성도 | 배치/제거가 가능한 플레이 가능한 게임 |
