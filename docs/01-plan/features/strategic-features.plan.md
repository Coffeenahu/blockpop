# PDCA 계획서 - Stage 3: 전략적 기능 강화 (Hold, Rotate, Shuffle, Multi-line)

## 1. 계획 (Plan)
### 목표
게임의 전략적 요소를 강화하여 플레이어에게 더 많은 선택지를 제공하고 고득점의 기회를 확장함.

### 사용자 추가 요청 및 밸런스 조정 사항 (최신)
- **Hold 시스템 유연화**: 그리드에 배치가 불가능한 상태(회색)의 블록도 Hold 슬롯에 넣거나 교체할 수 있어야 함.
- **Rotate 리필 밸런스**: **2000점당 1개**로 상향 조정. 최대 3회 스택.
- **Shuffle 리필 밸런스**: 1000점당 1개에서 **2000점당 1개**로 상향 조정.
- **UI 레이아웃 개편**: 
    - 상단 "BLOCK POP" 제목 삭제.
    - Hold, Shuffle, Rotate 버튼을 모두 대기 블록 영역 하단으로 이동하여 모바일 가림 현상 해결.
    - **우측 여백 복구**: 게임 화면이 좌측으로 쏠리는 현상을 해결하고 중앙 정렬 및 여백 확보.
- **Rotate 조작 방식 변경**: 
    - 개별 버튼 방식에서 **모드(Mode)** 방식으로 변경.
    - 'Rotate' 버튼을 누르면 회전 모드가 활성화되고, 그 상태에서 대기 블록을 터치하면 해당 블록이 90도 회전하며 회전권 1개 소모.
- **강제 게임오버 방지 및 가이드**:
    - 새로운 블록 3개가 생성될 때, **적어도 1개는 현재 그리드에 배치 가능한 블록**이 나오도록 보장하는 로직 추가.
    - **Hold 슬롯 유도**: 대기 블록이 1개만 남았고 그 블록이 배치 불가능한 경우, **Hold 슬롯이 비어 있다면** 게임오버를 시키지 않고 Hold 슬롯으로 옮기라는 안내(메시지 또는 시각 효과)를 제공.
- **버그 수정**:
    - **플로팅 이미지 복구**: 블록을 집었을 때 포인터 위쪽에 블록 이미지가 나타나지 않는 문제 수정.
    - **Hold 이동 시 다음 라운드 시작**: 마지막 블록을 Hold 슬롯으로 보관하여 대기 슬롯이 모두 비었을 때, 즉시 새로운 블록 3개가 생성되도록 수정.

### 주요 요구 사항
- **Hold**: 블록 1개를 별도 슬롯에 보관 및 교체 (턴당 1회).
- **Rotate**: 90도 시계 방향 회전 (회전권 소모). 배치 불가 블록도 회전 가능.
- **Shuffle**: 대기 블록 3개를 즉시 교체 (1000점당 1회 충전, 최대 2회).
- **Multi-line**: 2줄 이상 동시 제거 시 점수 제곱 배율 및 전용 텍스트 연출.
