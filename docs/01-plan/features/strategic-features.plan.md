# PDCA 계획서 - Stage 3: 전략적 기능 강화 (Hold, Rotate, Shuffle, Multi-line)

## 1. 계획 (Plan)
### 목표
게임의 전략적 요소를 강화하여 플레이어에게 더 많은 선택지를 제공하고 고득점의 기회를 확장함.

### 사용자 추가 요청 및 밸런스 조정 사항 (최신)
- **Hold 시스템 유연화**: 그리드에 배치가 불가능한 상태(회색)의 블록도 Hold 슬롯에 넣거나 교체할 수 있어야 함.
- **Rotate 리필 밸런스**: **2000점당 1개**로 상향 조정. 최대 3회 스택.
- **Shuffle 리필 밸런스**: 1000점당 1개에서 **2000점당 1개**로 상향 조정.
- **모바일 UI 최적화**: Rotate 버튼이 브라우저 주소창/내비게이션 바에 가리지 않도록 하단 여백 및 레이아웃 조정.
- **강제 게임오버 방지**: 새로운 블록 3개가 생성될 때, **적어도 1개는 현재 그리드에 배치 가능한 블록**이 나오도록 보장하는 로직 추가.

### 주요 요구 사항
- **Hold**: 블록 1개를 별도 슬롯에 보관 및 교체 (턴당 1회).
- **Rotate**: 90도 시계 방향 회전 (회전권 소모). 배치 불가 블록도 회전 가능.
- **Shuffle**: 대기 블록 3개를 즉시 교체 (1000점당 1회 충전, 최대 2회).
- **Multi-line**: 2줄 이상 동시 제거 시 점수 제곱 배율 및 전용 텍스트 연출.

## 2. 설계 (Design)
