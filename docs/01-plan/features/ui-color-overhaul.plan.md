# PDCA Plan: UI 컬러 스킴 개편 (UI Color Overhaul)

> UI의 전체적인 색감을 일관성 있게 변경하고, 시각적 품질을 개선하기 위한 계획입니다.

## 1. 개요 (Overview)
- **목표**: 현재의 혼재된 색상 체계를 정리하고, 세련된 느낌의 새로운 테마(예: 현대적인 다크 테마 또는 부드러운 파스텔 테마)를 적용합니다.
- **배경**: 현재 블록 색상과 UI 요소(버튼, 텍스트)의 색상이 각각 하드코딩되어 있어 일관성이 부족하고 관리가 어렵습니다.

## 2. 범위 (Scope)
- **블록 색상**: `constants.ts`의 `BLOCK_COLORS` 팔레트 업데이트.
- **전역 스타일**: `App.css`의 CSS 변수(`--bg-color`, `--grid-bg`, `--text-color` 등) 수정.
- **UI 요소**: `App.css` 내 하드코딩된 버튼(부활, 회전, 셔플), 점수판, 콤보 효과 색상 수정.
- **애니메이션 효과**: 파티클 및 팝업 점수 효과의 색상 일관성 확보.

## 3. 세부 계획 (Task List)
- [ ] **[Research]** 새로운 컬러 팔레트 선정 (Primary, Secondary, Accent colors)
- [ ] **[Design]** 컬러 가이드 작성 (CSS 변수 및 블록 팔레트 정의)
- [ ] **[Implementation]** `constants.ts` 및 `App.css` 반영
- [ ] **[Validation]** UI 요소 간의 대비(Contrast) 및 가독성 확인

## 4. 예상 결과 (Expected Outcome)
- 더욱 전문적이고 세련된 게임 분위기 조성.
- 테마 변경 시 관리 효율성 증대.

## 6. 사용자 피드백 반영 (User Feedback)
