# Combo System & Block Diversity Completion Report

> Version: 1.0.0 | Created: 2026-03-09

## Summary
'Block Pop'의 첫 번째 주요 개선 사항인 콤보 시스템과 블록 다양화 개발을 완료했습니다. 단순한 블록 배치를 넘어 연속적인 줄 제거를 통한 점수 획득과 고난도 블록 관리가 필요한 전략적 퍼즐 게임으로 진화했습니다.

## Metrics
- **Match Rate**: 100% (초기 설계 대비 모든 기능 구현 및 버그 수정 완료)
- **Iterations**: 3회 (기능 구현 -> 버그 수정 -> UI/UX 폴리싱)
- **Duration**: 1일

## Key Achievements
1. **콤보 유예(Grace) 시스템**: 줄을 지우지 못해도 3번의 배치 기회 동안 콤보를 유지할 수 있는 전략적 요소 도입.
2. **블록 다양화 및 동적 난이도**: 7종의 새로운 블록 추가 및 점수대별 가중치 생성 로직 구현.
3. **UI/UX 폴리싱**:
    - 2콤보 이상일 때만 나타나는 콤보 텍스트 및 화면 흔들림 효과로 세련된 타격감 구현.
    - 줄이 터지는 중에도 다음 블록을 계획할 수 있는 실시간 배치 가이드 로직 적용.
4. **크리티컬 버그 해결**: 블록을 하나 배치할 때마다 전체 블록이 바뀌던 설계 오류를 해결하여 전략적 보관이 가능해짐.

## Lessons Learned
- React의 `useEffect` 의존성 관리가 게임 엔진 로직(블록 생성 등)에 미치는 영향을 다시 한번 확인했으며, 상태 의존성을 끊고 명시적인 호출 방식을 사용하는 것이 게임 루프 설계에 유리함을 배움.
- 콤보 유예 시스템은 플레이어의 심리적 압박감을 줄이면서도 성취감을 높이는 좋은 장치임을 확인함.
